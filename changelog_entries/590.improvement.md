The GuPPy app has a white header with the GuPPy logo, wordmark and a rainbow rule in the logo's colors, progress bars that fill with the logo's gradient, and plot colors set by meaning: the signal and everything derived from it is green, the isosbestic control blue, covariates violet, highlighted marks red, and each tonic epoch its own color. Every page's text is set in Inter, with JetBrains Mono for literals, both bundled with GuPPy, on one type scale of four sizes and two weights, labels, buttons and headings are in Title Case, with units but no Python types, and plot text is set in Helvetica or Arial at sizes that stay legible in a saved figure. The NWB metadata form uses the homepage's cards and white sections. Each Visualization plot has one labeled toolbar, sits in a homepage card on tabs with several plots, and has its event or trial picker beside it in a panel that resizes or hides.
