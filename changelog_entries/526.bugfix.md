Neurophotometrics recordings are now demultiplexed by testing the excitation bit of each frame's `LedState`/`Flags` word, so a recording that writes one excitation under several values — `sampleData_NPM_4` writes 415 nm as both 17 and 273 — or strobes two LEDs into one frame is read correctly, and a dropped frame no longer misassigns every sample after it. A file whose header carries blank cells, or a second timestamp column beside one named `Timestamp`, now opens the Label Stores page, and a problem with an NPM configuration is reported in the page's alert pane rather than only in the terminal running the server.
