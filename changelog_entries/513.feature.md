Analysis outputs no longer land inside the session folder. A new **Root Folder Selection** card names two folders a project keeps for the life of its analyses — an **input root folder** your sessions live under and an **output root folder** results are written to — and GuPPy mirrors each session's path below the input root into the output root, writing its run folders there as `output_<run name>`. A session at `<input root>/subject1/session1` gets `<output root>/subject1/session1/output_1`. Mirroring the input structure means the results tree is navigable without documentation and two sessions sharing a folder name never collide. Both folders are required. Ticking **Output root folder is the same as the input root folder** points both at one folder, which writes each session's runs inside it — the pre-2.0.0-beta4 arrangement, available but not recommended. Run folders written by earlier versions are still found and still open, and occupy their run name so a new run never collides with one; reading that older name is deprecated.
